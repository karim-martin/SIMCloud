Programming Fundamentals

Object-oriented programming with C#, and the data structures and algorithms behind every application you will ever build - explained from scratch.

Start here if you are new

You do not need any prior theory to read this section. Every idea is introduced in plain English first, then shown as a small, complete C# example you can paste into a console app and run. Work top to bottom: OOP teaches you how to organise code, and Data Structures & Algorithms teaches you how to make it fast.

Why these two topics?

Almost every problem in application development is one of two kinds:

  • "How do I keep this code from turning into a mess?" - the answer is design, and object-oriented programming is the dominant design style in C#, Java, Python, and TypeScript.
  • "Why is this slow?" - the answer is almost always the wrong data structure or the wrong algorithm. Choosing a Dictionary over a List can turn a 10-second report into a 10-millisecond one.

The examples here use C#, but the ideas transfer directly. Rename a few keywords and the same code is Java; the same concepts appear in Python, TypeScript, Go, and Rust.

Object-Oriented Programming

OOP models a program as a set of objects - small bundles of data and the behaviour that acts on that data - which cooperate by calling each other's methods.

OOP Overview

What OOP is, the problem it solves, and how procedural code turns into object-oriented code.

Building Blocks

Class, object, fields and properties, methods, message passing, constructors and destructors.

Encapsulation

Bundle data with the methods that change it, and lock the door on everything else.

Abstraction

Expose only essential behaviour with abstract classes and interfaces; hide the implementation.

Inheritance

Derive a class from another to reuse and extend behaviour - and know when not to.

Polymorphism

One interface, many implementations, through method overriding and overloading.

Data Structures & Algorithms

A data structure decides how data is arranged in memory. An algorithm is the recipe you run over it. Together they decide whether your code finishes instantly or times out.

Running the examples

Every example is plain C# that runs on the .NET SDK. Create a scratch project once and paste examples into Program.cs:

# Install the .NET SDK, then:
dotnet new console -o PlaygroundApp
cd PlaygroundApp

# Paste an example into Program.cs, then run it:
dotnet run

The examples target .NET 8 and use top-level statements where it keeps things short - that is why some snippets have no Main method.
