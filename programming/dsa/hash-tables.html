Hash Tables & Sets

Turn a key into an array index with a hash function, and lookup stops depending on how much data you have.

Hash table in one sentence

A hash table is an array plus a bit of maths. A hash function turns your key ("ada@example.com") into a number, that number picks an array slot, and the value is stored there. Looking it up runs the same maths and jumps straight to the slot - no searching.

How it works, step by step

Say the internal array has 8 slots and we store "Ada" -> 42:

1

Hash the key

"Ada".GetHashCode() returns some integer, say 1,842,761,913.

2

Map it into the array

Take the remainder: 1,842,761,913 % 8 = 1. So slot 1.

3

Store the key and the value

Slot 1 now holds the pair ("Ada", 42). The key is stored too - that is how collisions are resolved later.

4

Look up by repeating steps 1-2

Hash "Ada" again, get slot 1, compare the stored key, return 42. Constant work regardless of how many entries exist.

Collisions

Two different keys can hash into the same slot - "Ada" and "Bob" might both land in slot 1. That is a collision, and it is normal, not a bug. The usual fix is chaining: each slot holds a small list of entries, and lookup compares keys within that list.

Buckets with chaining
Slot 0
empty
Slot 1
("Ada", 42) → ("Bob", 7)
Slot 2
("Grace", 99)

empty

As long as the chains stay short, lookup is effectively O(1). Two things keep them short:

  • A good hash function - one that scatters keys evenly across the slots.
  • Resizing - when the table gets too full (the load factor rises), it allocates a bigger array and rehashes everything into it.
The worst case is O(n)

If every key hashes to the same slot, every lookup walks one long chain and the hash table degrades into a linked list. In practice this only happens with a badly written GetHashCode - or, in a public-facing service, a deliberate hash-collision attack. .NET randomises string hashing per process to defend against that.

Dictionary<TKey, TValue>

var ages = new Dictionary<string, int>();

// Add - throws if the key already exists
ages.Add("Ada", 36);

// Indexer - adds or overwrites, no exception
ages["Alan"] = 41;
ages["Ada"] = 37;                      // updates the existing entry

Console.WriteLine(ages["Ada"]);        // 37        O(1)
Console.WriteLine(ages.Count);         // 2

// The safe way to read - no exception when the key is missing
if (ages.TryGetValue("Grace", out int age))
    Console.WriteLine(age);
else
    Console.WriteLine("Not found");    // Not found

Console.WriteLine(ages.ContainsKey("Alan"));    // True   O(1)
Console.WriteLine(ages.ContainsValue(37));      // True   O(n) - values are not hashed

ages.Remove("Alan");                            // O(1)

// Iterating - order is NOT guaranteed, do not rely on it
foreach (KeyValuePair<string, int> pair in ages)
    Console.WriteLine($"{pair.Key} is {pair.Value}");

foreach ((string name, int a) in ages)          // deconstruction, C# 7+
    Console.WriteLine($"{name} is {a}");
Prefer TryGetValue

if (d.ContainsKey(k)) { var v = d[k]; } hashes the key twice. d.TryGetValue(k, out var v) does it once and reads better. Use TryAdd for the same reason when adding.

Useful patterns

// Counting occurrences - the single most common dictionary use
string text = "the quick brown fox jumps over the lazy dog the end";
var counts = new Dictionary<string, int>();

foreach (string word in text.Split(' '))
{
    counts.TryGetValue(word, out int current);   // missing key gives 0
    counts[word] = current + 1;
}

foreach (var pair in counts.OrderByDescending(p => p.Value).Take(3))
    Console.WriteLine($"{pair.Key}: {pair.Value}");     // the: 3, ...

// Grouping - a dictionary of lists
var byLength = new Dictionary<int, List<string>>();
foreach (string word in text.Split(' '))
{
    if (!byLength.TryGetValue(word.Length, out List<string>? bucket))
        byLength[word.Length] = bucket = new List<string>();
    bucket.Add(word);
}

// LINQ does both in one line
var counts2 = text.Split(' ').GroupBy(w => w).ToDictionary(g => g.Key, g => g.Count());
var byLength2 = text.Split(' ').ToLookup(w => w.Length);

// Case-insensitive keys - pass a comparer
var settings = new Dictionary<string, string>(StringComparer.OrdinalIgnoreCase);
settings["ApiKey"] = "abc123";
Console.WriteLine(settings["APIKEY"]);          // abc123

HashSet<T> - membership, not mapping

A set is a hash table that stores only keys. Use it whenever the question is "have I seen this?" or "is this in the allowed list?".

var seen = new HashSet<string>();

Console.WriteLine(seen.Add("ada"));     // True  - added
Console.WriteLine(seen.Add("ada"));     // False - already present, not added again
Console.WriteLine(seen.Contains("ada"));// True                   O(1)
Console.WriteLine(seen.Count);          // 1

// Deduplicating a list - O(n) instead of the O(n²) nested-loop version
var numbers = new List<int> { 1, 2, 2, 3, 3, 3, 4 };
var unique = new HashSet<int>(numbers);          // 1 2 3 4
List<int> uniqueList = numbers.Distinct().ToList();

// Set algebra
var a = new HashSet<int> { 1, 2, 3, 4 };
var b = new HashSet<int> { 3, 4, 5 };

var union = new HashSet<int>(a); union.UnionWith(b);              // 1 2 3 4 5
var inter = new HashSet<int>(a); inter.IntersectWith(b);          // 3 4
var diff  = new HashSet<int>(a); diff.ExceptWith(b);              // 1 2

Console.WriteLine(a.IsSupersetOf(new[] { 1, 2 }));                // True
Console.WriteLine(a.Overlaps(b));                                 // True

Using your own class as a key

A hash table finds the bucket with GetHashCode() and confirms the match with Equals(). If you use a custom class as a key without overriding both, .NET falls back to reference equality - and two objects with identical contents will be treated as different keys.

// BROKEN - no overrides, so equal-looking keys do not match
public class Point { public int X, Y; }

var d = new Dictionary<Point, string>();
d[new Point { X = 1, Y = 2 }] = "first";
Console.WriteLine(d.ContainsKey(new Point { X = 1, Y = 2 }));   // False!
// FIXED - value-based equality and a matching hash code
public class Point : IEquatable<Point>
{
    public int X { get; init; }
    public int Y { get; init; }

    public bool Equals(Point? other) =>
        other is not null && other.X == X && other.Y == Y;

    public override bool Equals(object? obj) => Equals(obj as Point);

    // MUST agree with Equals: equal objects must return the same hash code
    public override int GetHashCode() => HashCode.Combine(X, Y);
}

var d2 = new Dictionary<Point, string>();
d2[new Point { X = 1, Y = 2 }] = "first";
Console.WriteLine(d2.ContainsKey(new Point { X = 1, Y = 2 }));  // True
// EASIEST - a record generates Equals and GetHashCode for you
public record PointRecord(int X, int Y);

var d3 = new Dictionary<PointRecord, string>();
d3[new PointRecord(1, 2)] = "first";
Console.WriteLine(d3.ContainsKey(new PointRecord(1, 2)));            // True
Never mutate a key after inserting it

Changing a field that GetHashCode depends on moves the key's "correct" bucket without moving the entry. The item becomes unreachable - present in the dictionary, but no lookup will ever find it. Use immutable types (records, init-only properties) as keys.

A working mini hash table

Chaining, resizing, and all - about 60 lines:

public class MyHashTable<TKey, TValue> where TKey : notnull
{
    private class Entry
    {
        public TKey Key = default!;
        public TValue Value = default!;
        public Entry? Next;                      // the chain for this bucket
    }

    private Entry?[] _buckets = new Entry?[8];
    private int _count;

    // Load factor: resize once the table is 75% full, to keep chains short
    private const double MaxLoad = 0.75;

    public int Count => _count;

    private int BucketFor(TKey key, int bucketCount)
    {
        // & int.MaxValue clears the sign bit: GetHashCode can return a negative
        int hash = key.GetHashCode() & int.MaxValue;
        return hash % bucketCount;
    }

    public void Set(TKey key, TValue value)
    {
        int index = BucketFor(key, _buckets.Length);

        // Walk the chain: update if the key is already here
        for (Entry? e = _buckets[index]; e is not null; e = e.Next)
        {
            if (EqualityComparer<TKey>.Default.Equals(e.Key, key))
            {
                e.Value = value;
                return;
            }
        }

        // Not found - add to the front of the chain
        _buckets[index] = new Entry { Key = key, Value = value, Next = _buckets[index] };
        _count++;

        if (_count > _buckets.Length * MaxLoad) Resize();
    }

    public bool TryGet(TKey key, out TValue value)
    {
        int index = BucketFor(key, _buckets.Length);

        for (Entry? e = _buckets[index]; e is not null; e = e.Next)
        {
            if (EqualityComparer<TKey>.Default.Equals(e.Key, key))
            {
                value = e.Value;
                return true;
            }
        }

        value = default!;
        return false;
    }

    public bool Remove(TKey key)
    {
        int index = BucketFor(key, _buckets.Length);
        Entry? previous = null;

        for (Entry? e = _buckets[index]; e is not null; e = e.Next)
        {
            if (EqualityComparer<TKey>.Default.Equals(e.Key, key))
            {
                if (previous is null) _buckets[index] = e.Next;
                else previous.Next = e.Next;
                _count--;
                return true;
            }
            previous = e;
        }
        return false;
    }

    private void Resize()
    {
        var bigger = new Entry?[_buckets.Length * 2];

        // Every key must be rehashed - the bucket count changed
        foreach (Entry? head in _buckets)
        {
            for (Entry? e = head; e is not null;)
            {
                Entry? next = e.Next;
                int index = BucketFor(e.Key, bigger.Length);
                e.Next = bigger[index];
                bigger[index] = e;
                e = next;
            }
        }

        _buckets = bigger;
    }
}
var table = new MyHashTable<string, int>();
table.Set("Ada", 36);
table.Set("Alan", 41);
table.Set("Ada", 37);                      // updates, does not duplicate

Console.WriteLine(table.Count);            // 2
Console.WriteLine(table.TryGet("Ada", out int v) ? v : -1);      // 37
Console.WriteLine(table.Remove("Alan"));   // True
Console.WriteLine(table.TryGet("Alan", out _));                  // False
